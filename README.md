# Ayush Yadav — Portfolio

Personal engineering portfolio for **Embedded Systems & Firmware**, with **Digital Design** as a secondary focus.

## Run locally

Open `index.html` in a browser. The site is a lightweight static page and does not require a build step or external JavaScript dependencies.

## Deploy with GitHub Pages

This repository is named `ayush-ydv09.github.io`. In GitHub, open **Settings → Pages** and select **Deploy from a branch**, then choose `main` and the `/ (root)` folder if Pages is not already enabled.

## Content

The portfolio highlights selected public projects, current engineering interests, and contact links. Project descriptions are kept grounded in the work documented in their repositories.
